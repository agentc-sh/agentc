---
title: Runtime configuration
description: Runtime configuration fields, defaults, and environment variables for the standalone binary.
---

The standalone binary loads its generated configuration from embedded values and the process
environment when a command uses it. Configuration fields come from the selected components and
the manifest. Changes to environment variables take effect when configuration is loaded again.

Use the [config command](/reference/archetypes/standalone/cli#config) to inspect resolved values.

## Configuration shape

The tables below describe configuration paths in the generated binary. Fields marked
`manifest value` take their value or runtime fallback from the resolved manifest. A field listed
as conditional is generated only when its corresponding configuration is present.

`…` indicates a required value with no default. `null` indicates an optional value. Fields with
types linked below have their own shape definitions on this page. `JSON value` means arbitrary
JSON data whose structure is defined by its consumer.

### Config

| Field | Type | Availability | Default | Description |
|-------|------|--------------|---------|-------------|
| `default_tenant_id` | string | Generated configuration | `default`, or manifest value | Tenant used when the caller supplies no tenant. |
| `agent` | [AgentConfig](#agentconfig) | Generated agent fields | Manifest values | Agent model and optional prompt configuration. |
| `provider` | [ProviderConfigs](#providerconfigs) | Providers with generated fields | Manifest values | Credentials, endpoints, and inference settings keyed by provider. |
| `tool` | [ToolConfigs](#toolconfigs) | JavaScript, Python, or Bash tools | Manifest values | Tool activation and tool-defined configuration. |
| `server` | [ServerConfig](#serverconfig) | `http_server` enabled | Defaults below, or manifest values | HTTP listener settings. |
| `filesystem` | [FilesystemConfig](#filesystemconfig) | Generated configuration | Defaults below | Host directories mounted into the virtual filesystem. |
| `network` | [NetworkConfig](#networkconfig) | Generated configuration | Defaults below, or manifest values | Outbound HTTP settings and access policy. |
| `mcp` | [McpConfig](#mcpconfig) | Generated configuration | Manifest values, or empty servers | MCP server transports. |
| `a2a` | [A2aConfig](#a2aconfig) | Generated configuration | Manifest values, or empty agents | Outbound A2A targets. |
| `database` | [DatabaseConfig](#databaseconfig) | ReAct graph | Defaults below | Persistence connections and migration settings. |
| `react` | [ReActConfig](#reactconfig) | ReAct graph | Defaults below, or manifest values | Graph-level model call policy. |
| `task_queue` | [TaskQueueConfig](#taskqueueconfig) | ReAct graph with HTTP server | Defaults below | Queued work and batching limits. |
| `pubsub` | [MemoryPubSub](#memorypubsub) \| [RedisPubSub](#redispubsub) | ReAct graph with HTTP server | Memory transport, capacity `4096` | Transport for distributing live run events. |

Inspect a particular binary with the [config command](/reference/archetypes/standalone/cli#config).
Custom blocks can contribute additional configuration fields.

### ProviderConfigs

Path: `provider`. Each generated field is the configuration key of a declared provider.
Provider labels containing punctuation are converted to snake case for this key.

| Field | Type | Description |
|-------|------|-------------|
| `<provider_key>` | [ProviderConfig](#providerconfig) | Settings for the provider with this configuration key. |

### ProviderConfig

Path: `provider.<provider_key>`. Only configured fields are generated. Values and runtime
fallbacks come from the corresponding [provider declaration](/reference/manifest/providers).

| Field | Type | Availability | Description |
|-------|------|--------------|-------------|
| `api_key` | string | Configured for a provider supporting credentials | Authentication key. |
| `base_url` | string | Configured for Anthropic, OpenAI, Ollama, or Hugging Face | Service endpoint. |
| `params` | [InferenceParams](#inferenceparams) | Provider-level parameters configured | Inference defaults shared by the provider's models. |
| `<model_key>` | [InferenceParams](#inferenceparams) | Parameters configured for that model | Inference settings for an individual model. |

Model keys replace each non-alphanumeric character in the model name with `_`. For example,
`google/gemma-2-2b-it` becomes `google_gemma_2_2b_it`. A model's settings live directly under this
key, such as `provider.cloud.google_gemma_2_2b_it.temperature`.

### InferenceParams

Only configured parameters are generated. Each takes its value or runtime fallback from the
corresponding provider or model declaration.

| Field | Type | Description |
|-------|------|-------------|
| `max_tokens` | integer | Maximum output token count. |
| `temperature` | number | Sampling temperature. |
| `top_p` | number | Probability mass used for nucleus sampling. |
| `top_k` | integer | Maximum candidate tokens considered during sampling. |
| `stop_sequences` | array&lt;string&gt; | Sequences that end generation. |
| `frequency_penalty` | number | Penalty based on token repetition frequency. |
| `presence_penalty` | number | Penalty for tokens already present in the response. |
| `seed` | integer | Sampling seed. |
| `provider_params` | JSON value | Provider-specific inference settings. |

### NetworkPolicy

Path: `network.policy`.

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `addresses` | [NetworkAddresses](#networkaddresses) | Defaults below | Permitted destination address categories. |
| `methods` | array&lt;string&gt; \| null | `null` | Permitted HTTP methods. `null` permits all methods. |
| `allow` | array&lt;[NetworkUrlPattern](#networkurlpattern)&gt; | `[]` | URL patterns that requests must match. An empty array denies every URL. |

### NetworkAddresses

Path: `network.policy.addresses`.

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `allow_loopback` | boolean | `false` | Allow this machine's loopback addresses, such as `127.0.0.1` and `::1`. |
| `allow_private` | boolean | `false` | Allow private-network destinations, such as `10.0.0.1` and `192.168.1.1`. |
| `allow_link_local` | boolean | `false` | Allow addresses on the immediately connected network, such as `169.254.0.1`, including cloud metadata addresses. |

### NetworkUrlPattern

Path: `network.policy.allow.<index>`.

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `protocol` | string \| null | `null` | URL scheme pattern. |
| `hostname` | string \| null | `null` | Host name pattern. |
| `port` | string \| null | `null` | Port pattern. |
| `pathname` | string \| null | `null` | URL path pattern. |

A `null` component matches any value. See [URL patterns](/reference/manifest/network#allow)
for pattern syntax.

```bash
export AGENT__NETWORK__POLICY__ALLOW__0__HOSTNAME=somehost.com
```

### A2aTenant

Path: `a2a.agents.<label>.tenant`.

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `policy` | `inherit` \| `none` \| `fixed` | `inherit` for an omitted tenant | Tenant selection policy. |
| `id` | string | … | Tenant ID, required for `fixed`. |

identity. `fixed` forwards `id`.

### Duration

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `secs` | integer | … | Whole seconds. |
| `nanos` | integer | … | Additional nanoseconds. |

For example, configure a ten-second connection acquisition timeout:

```bash

export AGENT__DATABASE__OPTIONS__ACQUIRE_TIMEOUT__SECS=10
export AGENT__DATABASE__OPTIONS__ACQUIRE_TIMEOUT__NANOS=0
```

## Fixed and runtime values

| Manifest value | Configuration behavior |
|----------------|------------------------|
| A literal value | Embedded as a fixed value. An environment override targeting it fails configuration loading. |
| `runtime("NAME", default)` | Read from the environment, with the embedded default as fallback. |
| `runtime("NAME")` | Read from the environment. A required field must have a value when configuration is loaded. |

For manifest expression syntax, see [Runtime values](/reference/manifest#runtime-values).

Fields supplied by configuration sections also have their own defaults. A field's manifest or
component reference defines its settings and defaults.

## Environment variable names

The prefix is `AGENT__`. Separate nested field names with `__` and write them in uppercase:

| Configuration path | Environment variable |
|--------------------|----------------------|
| `default_tenant_id` | `AGENT__DEFAULT_TENANT_ID` |
| `server.port` | `AGENT__SERVER__PORT` |
| `database.primary` | `AGENT__DATABASE__PRIMARY` |

The field must be present in the binary's generated configuration and permit environment values.
For example, server fields are generated when the HTTP server is enabled.

A `runtime("NAME", ...)` expression also maps `NAME` to that field. Both the named variable and
its `AGENT__...` form address the same setting. When both set that setting, the named variable wins.

```hcl title="agent.acl"
http_server {
  port = runtime("HTTP_PORT", 8080)
}
```

```bash
export AGENT__SERVER__PORT=8081
export HTTP_PORT=9090
```

The resolved port is `9090`. With both variables unset, it is `8080`.

Aliases also support nested keys and list positions using the same `__` separator. For example:

```hcl title="agent.acl"
network {
  policy {
    allow = runtime("ALLOW", [])
  }
}
```

```bash
export ALLOW__0__HOSTNAME=somehost.com
export ALLOW__0__PORT=8080
```

These variables set the first allowed URL pattern's hostname and port. `ALLOW__0__PORT` addresses
the same field as `AGENT__NETWORK__POLICY__ALLOW__0__PORT`.

## Value formats

Write scalar values as text. Numbers are parsed into the field's numeric type, and `true` or
`false` set boolean fields. Lists and maps accept delimited field paths or JSON values:

```bash
export AGENT__DATABASE__AUTO_MIGRATE=false
export AGENT__DATABASE__REPLICAS__0=postgresql://user:password@replica:5432/dbname
```

Nested keys address individual fields. Numeric segments address list positions, as `0` does above.

Alternatively, supply a complete list or map as a JSON value:

```bash
export AGENT__DATABASE__REPLICAS='["postgresql://user:password@replica:5432/dbname"]'
```

When both a parent value and a nested value are supplied, the parent is applied first and the
nested value is applied afterward.

An empty environment value unsets its configuration path after embedded defaults are applied.
The field's type and defaults determine the resulting value or missing-value error.

## Configuration errors

Configuration loading fails when a required value is missing, a value cannot be parsed into its
field's type, or an environment variable attempts to change a fixed value. The error identifies
the affected configuration path.
