```js
import { fetch } from "agentc:http"
```

`fetch`, `Headers`, and `Response` are also installed as globals as the same values this library
exports, so the import is optional for those three.

### fetch

<LibTags>
  <LibTag name="async" />
</LibTags>

<LibSignature>

</LibSignature>

Makes an HTTP request and resolves once the response head has arrived.

<LibParams>
  <LibParam name="url" type="string" required>
    The URL to request. It must be a string. A `URL` instance is refused.
  </LibParam>
  <LibParam name="init" type={<><Link href="#fetchinit">FetchInit</Link></>}>
    The method, headers, and body.
  </LibParam>
</LibParams>

<LibReturns type="Promise<Response>">
  The response to the request.
</LibReturns>

<LibThrows>
  <LibThrow when="the request is refused by the egress policy" />
  <LibThrow when="a configured limit is exceeded" />
  <LibThrow when="the connection fails" />
</LibThrows>

## What this client does not have

The fetch surface does not include `Request`, `FormData`, `Blob` request bodies,
`AbortController`, `AbortSignal`, or the `signal`, `redirect`, `credentials`, `mode`, and `cache`
fields on the init object. Guest code cannot construct a `Response` or `Headers`. Streaming request
bodies are not supported. Response bodies do stream.
