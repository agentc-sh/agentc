`agentc:tools` provides the classes and types used to define and invoke a tool. See
[tools](/reference/runtime/tools) for the lifecycle shared by every tool.

### Tool

<LibSignature>
```ts
abstract class Tool<Args, Result, State = unknown> {
  static readonly description: string
  static readonly parameters: Schema

  abstract execute(input: ToolInput<Args, State>): Promise<ToolOutput<Result>>
}
```
</LibSignature>

The abstract base class for every tool. Export a subclass and select it with the manifest's `export`
field. Its static `description` tells the model what the tool does, and static `parameters` supplies
the model-facing input schema.

A subclass that does not implement `execute` rejects with `a Tool subclass must implement execute`.
`execute` must return a promise.

### ToolInput

<LibTags>
  <LibTag name="not constructible" />
</LibTags>

<LibSignature>
```ts
class ToolInput<Args, State = unknown> {
  readonly args: Args
  readonly state: State
  readonly emit?: (delta: ActivityDelta) => void
}
```
</LibSignature>

The runtime creates one input for each invocation. Tool code cannot construct it.

<LibProperties>
  <LibProperty name="args" type="Args" readonly>
    The tool arguments.
  </LibProperty>
  <LibProperty name="state" type="State" readonly>
    The current graph state.
  </LibProperty>
  <LibProperty name="emit" type="(delta: ActivityDelta) => void" optional readonly>
    Sends a stateless activity update while the tool runs.
  </LibProperty>
</LibProperties>

## Types

### ToolOutput

<LibSignature>
```ts
type ToolOutput<Result> = {
  output: Result
  state_update?: PatchDocument
}
```
</LibSignature>

The value returned by `execute`. `output` is required. `state_update` is optional and contains
[RFC 6902 JSON Patch](https://datatracker.ietf.org/doc/html/rfc6902) operations. For ReAct state
updates, see [state](/reference/graph/react/state).

### ActivityDelta

<LibSignature>
```ts
type ActivityDelta = {
  activity_type: string
  patch: PatchDocument
}
```
</LibSignature>

The value passed to `input.emit?.(...)`. Its `patch` contains
[RFC 6902 JSON Patch](https://datatracker.ietf.org/doc/html/rfc6902) operations.
