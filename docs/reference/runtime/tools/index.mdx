title: Tools
description: The runtime contract used by tools.
---

The tools library is the runtime contract tools use to declare metadata and behavior and receive
invocation data.

<LibAvailability>
  <LibLanguage name="TypeScript" specifier="agentc:tools">
    The runtime provides `agentc:tools` to every JavaScript tool it executes.
  </LibLanguage>
  <LibLanguage name="Python" specifier="agentc_tools">
    The runtime provides `agentc_tools` to every Python tool it executes.
  </LibLanguage>
</LibAvailability>

## How to write tools

For information on how to write tools, see [Write a tool](/guides/write-a-tool).

## Bindings

See [TypeScript](/reference/runtime/tools/typescript) for the `agentc:tools` surface and
[Python](/reference/runtime/tools/python) for the `agentc_tools` surface.
