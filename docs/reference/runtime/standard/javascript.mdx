title: JavaScript
description: The node modules and globals the runtime implements for JavaScript components.

The modules below are implemented as a subset of their Node counterparts. Each one is available as
both `node:name` and `name`.

### node:timers

<LibProperties>
  <LibProperty name="setTimeout" type="(callback: () => void, delay?: number) => number">
    Schedules a callback to run once.
  </LibProperty>
  <LibProperty name="clearTimeout" type="(id?: number) => void">
    Cancels a timeout.
  </LibProperty>
  <LibProperty name="setInterval" type="(callback: () => void, delay?: number) => number">
    Schedules a callback to run repeatedly.
  </LibProperty>
  <LibProperty name="clearInterval" type="(id?: number) => void">
    Cancels an interval.
  </LibProperty>
  <LibProperty name="setImmediate" type="(callback: () => void) => number">
    Schedules a callback to run on the next immediate turn.
  </LibProperty>
  <LibProperty name="queueMicrotask" type="(callback: () => void) => void">
    Schedules a callback as a microtask.
  </LibProperty>
</LibProperties>

## What is not here

If a module or global is not listed on this page, the runtime does not provide it. The filesystem is
an agentc runtime library rather than part of this surface. See [agentc:fs](/reference/runtime/fs).
