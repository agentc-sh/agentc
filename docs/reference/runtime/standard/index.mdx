---
title: Standard library
description: The parts of each language's own standard library that the runtime implements.
---

The runtime implements a subset of the language's own standard library alongside the agentc runtime
libraries. The subset is enumerated rather than inferred, because the environment is assembled
rather than inherited.

What the language provides is its standard library. What agentc provides is a runtime library.

<LibAvailability>
  <LibLanguage name="JavaScript" specifier="node:">
    The runtime implements a subset of the JavaScript standard library surface under the `node:`
    prefix and the corresponding bare module names.
  </LibLanguage>
</LibAvailability>

See [JavaScript](/reference/runtime/standard/javascript) for the full module and global list.
