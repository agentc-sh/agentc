---
title: network
description: The network block declares the egress policy and limits for outbound requests.
---

The `network` block declares what the agent's outbound HTTP client may do.

```hcl title="agent.acl"
network {
  user_agent = runtime("NETWORK_USER_AGENT", "my-agent/1.0")

  headers = {
    "X-Env" = "production"
  }

  limits {
    request_timeout_ms = runtime("NETWORK_REQUEST_TIMEOUT_MS", 5000)
  }

  policy {
    allow = [
      {
        protocol = "https"
        hostname = "api.example.com"
      }
    ]
  }
}
```

## Fields

| Field | Type | Required | runtime() | Default | Description |
|-------|------|----------|-----------|---------|-------------|
| `user_agent` | string | no | yes | unset | The `User-Agent` header sent with every request. |
| `headers` | map&lt;string, string&gt; | no | yes | `{}` | Additional headers sent with every request. |
| `limits` | [NetworkLimits](#networklimits) | no | | defaults below | Connection, timeout, and size limits. |
| `policy` | [NetworkPolicy](#networkpolicy) | no | | defaults below | Rules governing the destination addresses, HTTP methods, and URLs available to outgoing requests. |

## NetworkLimits

| Field | Type | Required | runtime() | Default | Description |
|-------|------|----------|-----------|---------|-------------|
| `connect_timeout_ms` | integer | no | yes | unset | Time in milliseconds allowed to establish a connection. |
| `read_timeout_ms` | integer | no | yes | unset | Time in milliseconds allowed between response body chunks. |
| `request_timeout_ms` | integer | no | yes | unset | Time in milliseconds allowed for the entire request. |
| `max_redirects` | integer | no | yes | `5` | Number of redirects one request may follow. |
| `max_response_bytes` | integer | no | yes | unset | Maximum accepted response body size in bytes. |
| `concurrency_limit` | integer | no | yes | unset | Maximum requests in flight at once. |

An unset limit is not enforced.

## NetworkPolicy

The `policy` block contains `addresses`, `methods`, and `allow`.

### addresses

| Field | Type | Required | runtime() | Default | Description |
|-------|------|----------|-----------|---------|-------------|
| `allow_loopback` | boolean | no | yes | `false` | Allow requests to this machine through addresses such as `127.0.0.1` and `::1`. |
| `allow_private` | boolean | no | yes | `false` | Allow destinations on private networks, such as `10.0.0.1`, `192.168.1.1`, and IPv6 unique-local addresses. |
| `allow_link_local` | boolean | no | yes | `false` | Allow addresses usable only on the immediately connected network, such as `169.254.0.1`. |

These permit categories of destination address. The checks apply to every address a host name
resolves to. The link-local category is the one covering the cloud instance metadata address.

### methods

| Field | Type | Required | runtime() | Default | Description |
|-------|------|----------|-----------|---------|-------------|
| `methods` | array&lt;string&gt; | no | yes | unset (all methods) | HTTP methods the agent may use. |

### allow

`allow` is a list of WHATWG
[`URLPattern`](https://developer.mozilla.org/en-US/docs/Web/API/URL_Pattern_API) objects. An empty
list means URL patterns are unrestricted. Each pattern uses the `protocol`, `hostname`, `port`, and
`pathname` components. An omitted component matches anything.

| Field | Type | Required | runtime() | Default | Description |
|-------|------|----------|-----------|---------|-------------|
| `allow` | array&lt;[URLPattern](#urlpattern)&gt; | no | yes | `[]` | URL patterns the agent may request. |

#### URLPattern

| Field | Type | Required | runtime() | Default | Description |
|-------|------|----------|-----------|---------|-------------|
| `protocol` | string | no | no | any | URL scheme to match, such as `https`. |
| `hostname` | string | no | no | any | Host name to match, such as `api.example.com`. |
| `port` | string | no | no | any | Port to match in the request URL, such as `443`. |
| `pathname` | string | no | no | any | Path component to match in the request URL. |

In an HCL pattern, a whole-number port such as `port = 8086` is accepted as the string `"8086"`.

### Host name patterns

Host name matching follows `URLPattern` hostname semantics, which are label-aware rather than plain
substring matches.

- `*.acme.com` matches any number of leading labels.
- `:sub.acme.com` matches exactly one leading label.
- `api.acme.com` matches both patterns.
- `deep.api.acme.com` matches `*.acme.com`, but not `:sub.acme.com`.
- `evilacme.com` matches neither pattern, because `acme.com` is not a separate host label there.

[Control network egress](/guides/control-network-egress) for the step-by-step recipe.
