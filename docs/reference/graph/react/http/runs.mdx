---
title: Runs
description: The native HTTP endpoints for creating runs, streaming run events, and reading run history.
---

A run is one execution of the graph within a session. These endpoints list and read runs, and create
a new run whose events stream back as Server-Sent Events.

The stream keeps the connection alive with periodic `keep-alive` comments between events. A full run
looks like this on the wire:

```text
event: run_started
data: {"kind":"run_started","timestamp":1710000000.0,"session_id":"...","run_id":"..."}

event: messages_snapshot
data: {"kind":"messages_snapshot","timestamp":1710000000.1,"messages":[...]}

event: text_message_start
data: {"kind":"text_message_start","timestamp":1710000000.2,"message_id":"..."}

event: text_message_content
data: {"kind":"text_message_content","timestamp":1710000000.3,"message_id":"...","delta":"Hello"}

event: text_message_end
data: {"kind":"text_message_end","timestamp":1710000000.4,"message_id":"..."}

event: run_finished
data: {"kind":"run_finished","timestamp":1710000000.5,"session_id":"...","run_id":"...","status":"completed","interrupt_payload":null,"result":null}
```

### InferenceParams

Inference parameters for a model request. Every field is optional; omitted fields use the provider or
model defaults.

<Fields label="InferenceParams">
  <Field name="max_tokens" type="integer | null">
    Maximum number of tokens to generate.
  </Field>
  <Field name="temperature" type="float | null">
    Sampling temperature.
  </Field>
  <Field name="top_p" type="float | null">
    Nucleus sampling probability mass.
  </Field>
  <Field name="top_k" type="integer | null">
    Top-k sampling cutoff.
  </Field>
  <Field name="stop_sequences" type="string[] | null">
    Sequences that stop generation when produced.
  </Field>
  <Field name="frequency_penalty" type="float | null">
    Penalty applied in proportion to how often a token has appeared.
  </Field>
  <Field name="presence_penalty" type="float | null">
    Penalty applied to tokens that have already appeared at all.
  </Field>
  <Field name="seed" type="integer | null">
    Seed for deterministic sampling.
  </Field>
  <Field name="provider_params" type="object | null">
    Provider-specific parameters passed through unchanged.
  </Field>
</Fields>
