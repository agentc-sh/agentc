---
title: Messages
description: The native HTTP endpoints for creating, finding, reading, and deleting messages.
---

Messages are persisted separately from run state, so a client can read conversation history outside
of an active run and add messages to a session directly.

</Endpoint>

  </Field>
</Parameters>

<Parameters in="body">

  </Field>

## Types

### UserContent

A single content block in a user message. A user message carries an ordered array of these blocks, so
one message may mix text and media. The block is discriminated by `type`.

  <Variant label="image">

### MediaSource

The `source` of an image, audio, video, or document content block. It is either a URL to fetch or an
inline base64 payload, discriminated by `type`.

<Variants label="MediaSource">
  <Variant label="url">
    <Field name="type" type="string" enum={["url"]}>
      Identifies a URL source.
    </Field>
    <Field name="value" type="string">

    </Field>
  </Variant>
  <Variant label="base64">
    <Field name="type" type="string" enum={["base64"]}>
      Identifies inline base64 data.
    </Field>

  </Variant>
