---
title: Archetypes
description: Archetypes define the compiled artifact and the toolchain used to build it.
---

An archetype defines what the compiler generates and the toolchain used to build it. Choosing an
archetype means choosing the form of the deployable artifact.

Select it in the manifest's `build` block:

```hcl title="agent.acl"
build {
  archetype = "standalone"
}
```

The archetype and [graph](/concepts/the-graph) have separate responsibilities. The archetype defines
the output form. The graph defines the agent's execution behavior and domain interfaces. The compiler
composes their contributions into the generated application.

## Available archetypes

| Archetype | Artifact |
|-----------|----------|
| [standalone](/reference/archetypes/standalone) | Executable binary built from a generated Rust project. |
